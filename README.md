# 💰 Controle de Gastos Pessoais

> Um webapp moderno, rápido e responsivo para gestão financeira pessoal, desenvolvido para auxiliar no controle diário de receitas, despesas e acompanhamento visual por categorias.

---

## ✨ Funcionalidades

* **Painel de Indicadores (KPIs):** Visualização rápida das Receitas Totais, Despesas Totais e do Saldo Líquido do mês.
* **Gestão Completa de Transações:** Registo de despesas e receitas divididas por categorias específicas (Transporte, Mercado, Salário, Investimentos, etc.).
* **Edição e Exclusão Ágeis:** Permite corrigir ou remover lançamentos diretamente na tabela de extrato.
* **Filtros e Pesquisa Inteligente:** 
  * Filtro por mês/ano para acompanhar períodos específicos.
  * Pesquisa em tempo real por descrição ou categoria.
* **Gráficos Dinâmicos (Chart.js):** Distribuição visual em gráfico de pizza para analisar os custos por categoria, com opção de filtrar por dias específicos ou pelo mês todo.
* **Exportação para CSV:** Baixe o extrato filtrado do mês em formato de planilha para análises externas.
* **Modo Escuro (Dark Mode) Nativo:** Interface visualmente agradável, projetada com foco na ergonomia visual e conforto.
* **Armazenamento Local:** Todos os dados ficam salvos de forma segura e privada diretamente no armazenamento do seu navegador (`localStorage`), sem necessidade de configurar um banco de dados externo para uso rápido.

---
